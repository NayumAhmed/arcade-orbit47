## Important distinctions

- **Emulation:** runs software designed for another console; compatibility and performance vary.
- **Source port / engine reimplementation:** may provide a native PC experience, but often still needs original game data.
- **Recompilation / community port:** may be unofficial, experimental, or dependent on a specific game version.
- **Remake / clone:** may be a new implementation rather than the original game.

A repository existing on GitHub does not guarantee that a game is playable, safe, or legally redistributable. Prefer official releases, verify checksums when provided, inspect permissions and installers, and never download game files from untrusted mirrors.
